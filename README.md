# 🚀 TechnicalBabaOffice Website

A fully dynamic Personal Tech Brand website built with **PHP, MySQL & JavaScript**.

## Tech Stack
- **Backend**: PHP 8.x
- **Database**: MySQL
- **Frontend**: HTML5, CSS3, Vanilla JS + jQuery
- **Admin Panel**: AdminLTE 3.x

## Features
- 🏠 Dynamic Homepage with Hero, Stats & Featured Videos
- 📺 Services / Videos Page (YouTube embed support)
- 📬 Contact Form with Google Maps embed
- 🔐 Secure Admin Panel (AdminLTE) for full CRUD
- 📱 Fully Responsive (Mobile-first)
- 🌐 Hindi + English Bilingual

## Setup
1. Import `database/schema.sql` into your MySQL database
2. Edit `config/db.php` with your DB credentials
3. Run on XAMPP / LAMP at `localhost/TechnicalBabaOffice`

## Admin Panel
URL: `localhost/TechnicalBabaOffice/admin/`  
Default: **admin** / **admin@123** (change after first login!)
